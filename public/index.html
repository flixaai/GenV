SnapGen UI Extractor

Gunakan alat ini HANYA jika SnapGen melakukan update tampilan dan tombol Generate error. Alat ini akan menyedot struktur tombol terbaru mereka (format JSON) tanpa memotong kredit, sehingga Anda bisa mengupdate script robot.

🔑 Autentikasi

Gunakan header berikut pada setiap request ke /api/v1/*:

X-API-KEY: PUBLIC_API_KEY_ANDA

🎬 POST /api/v1/video/generate

cURL

curl -X POST BASE_URL/api/v1/video/generate \
  -H "Content-Type: application/json" \
  -H "X-API-KEY: PUBLIC_API_KEY_ANDA" \
  -d '{
    "provider": "Veo (Google AI)",
    "model": "Veo 2",
    "prompt": "A futuristic city at sunset",
    "image_reference": null,
    "orientation": "16:9",
    "resolution": "1080p",
    "duration": 10,
    "audio": true
  }'

JavaScript (Axios)

const axios = require('axios');

const res = await axios.post('BASE_URL/api/v1/video/generate', {
  provider: "Veo (Google AI)",
  model: "Veo 2",
  prompt: "A futuristic city at sunset",
  orientation: "16:9",
  resolution: "1080p",
  duration: 10,
  audio: true
}, { headers: { "X-API-KEY": "PUBLIC_API_KEY_ANDA" } });

console.log(res.data);
// { success: true, taskId: "TASK_12345", cost: 8 }

Python

import requests

res = requests.post("BASE_URL/api/v1/video/generate",
  headers={"X-API-KEY": "PUBLIC_API_KEY_ANDA"},
  json={
    "provider": "Veo (Google AI)",
    "model": "Veo 2",
    "prompt": "A futuristic city at sunset",
    "orientation": "16:9",
    "resolution": "1080p",
    "duration": 10,
    "audio": True
  })
print(res.json())

🖼️ POST /api/v1/image/generate

curl -X POST BASE_URL/api/v1/image/generate \
  -H "Content-Type: application/json" \
  -H "X-API-KEY: PUBLIC_API_KEY_ANDA" \
  -d '{
    "provider": "Imagen (Google AI)",
    "model": "Nano Banana Pro (Free)",

📊 GET /api/v1/task/status/:taskId

curl BASE_URL/api/v1/task/status/TASK_12345 \
  -H "X-API-KEY: PUBLIC_API_KEY_ANDA"

Response saat selesai:

{
  "success": true,
  "status": "completed",
  "type": "video",
  "mediaUrl": "BASE_URL/downloads/video_123.mp4",
  "previewUrl": "...",
  "creditsLeft": 10
}
